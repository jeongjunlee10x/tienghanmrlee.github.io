# Kho ảnh mới V3 — CHƯA TRIỂN KHAI ẢNH

Đây là địa chỉ chuẩn cho **170 tài nguyên tạo mới hoàn toàn**, chia thành 13 nhóm nội dung. Tham chiếu: `docs/MRLEE_V3_HUONG_DAN_TAO_170_ANH.md`.

- `hero-fresh.webp`: chỉ dùng ở Tươi mới; `hero-future.webp`: chỉ dùng ở Viễn tưởng.
- Nội dung HTML và thanh điều hướng không được ghép trực tiếp vào ảnh AI.
- Mỗi tệp ảnh phải có nguồn render độc lập và bản xem duyệt; không lấy ảnh V1/V2 để đổi tên.
- 4 thiết kế logo concept là ứng viên; chưa được phép ghi đè logo gốc.
- Việc GitHub tạo được README hoặc thư mục **không có nghĩa đã có các ảnh WebP thật**.

Bộ `manifest.json` và `*.prompt.txt` nguồn nằm trong ZIP phát hành từ cuộc trò chuyện. Các đường dẫn ảnh chỉ được kích hoạt sau khi upload binary và kiểm tra file thật.
