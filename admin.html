Trang quản trị riêng • Dữ liệu đồng bộ từ Firebase

Chỉ tài khoản đã được cấp quyền quản trị mới được truy cập dữ liệu học viên.

Thiết lập lần đầu: tạo dự án Supabase, chạy file SQL đi kèm và cấp quyền Admin cho tài khoản trước khi đăng nhập.
Dùng publishable/anon key của Supabase, tuyệt đối không dán service_role hoặc sb_secret. Cấu hình chỉ lưu trên trình duyệt hiện tại.
Đăng nhập bằng tài khoản Admin Supabase (không dùng tài khoản Firebase của học viên).

Dữ liệu học viên được đồng bộ một chiều từ Firebase qua GitHub Actions sau khi hoàn tất cấu hình. Không cần tài khoản Firebase để đăng nhập Admin.

Cấu hình quản trị

Trang quản trị đăng nhập bằng Supabase; bản sao dữ liệu học viên đồng bộ một chiều từ Firebase qua GitHub Actions. Chỉ các tài khoản có UID được thêm vào bảng mrlee_admins mới được đọc hoặc sửa dữ liệu.

Sau khi cài SQL và GitHub Secrets, học viên Firebase tự xuất hiện sau lần Actions chạy thành công. Không được đưa khóa Firebase service account hoặc Supabase secret vào HTML.
