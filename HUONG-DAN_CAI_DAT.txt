- SQL Editor > New Query > dan TOAN BO file supabase-setup.sql > Run.
- Authentication > Users > Add user: tao EMAIL va MAT KHAU quan tri.
  Neu tai khoan moi phai xac minh email, hoan tat viec xac minh.
- Sao chep User UID cua tai khoan quan tri trong Authentication > Users.
- SQL Editor > New Query > chay SQL nay, thay UID that:

  insert into public.mrlee_admins (user_id)
  values ('UID-THAT-CUA-ADMIN')
  on conflict (user_id) do nothing;

- Co the tat dang ky tai khoan tu do trong Authentication settings, vi
  trang quan tri chi dung tai khoan ban da cap.

6. RAT QUAN TRONG: CO SO DU LIEU DOC LAP
Trang Admin nay KHONG su dung Firebase. Vi du lieu hoc vien/hoc tap truoc
nay nam trong Firestore, kho admin moi SE TRONG cho toi khi:
  A. Ban tu them hoc vien, nhap diem vao admin; hoac
  B. Ban xuat du lieu duoc phep su dung thanh CSV roi nhap qua admin; hoac
  C. Lap trinh backend dong bo du lieu giua Firebase va Supabase.
C KHONG duoc bao gom trong bo nay. Tuyet doi khong nhung Firebase admin
credential hoac Supabase secret key vao HTML cong khai.
