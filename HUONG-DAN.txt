MR LEE - PHỎNG VẤN XIN VIỆC 100 CÂU MỚI
=======================================
1. Chép CAI-100-CAU-PHONG-VAN-XIN-VIEC.ps1 vào cùng thư mục với on-luyen-phong-van.html
2. Terminal VS Code:
   powershell -ExecutionPolicy Bypass -File .\CAI-100-CAU-PHONG-VAN-XIN-VIEC.ps1
3. Kiểm tra bằng Live Server: có 4 nút chủ đề mới. Không chép file MẪU thay file đang dùng nếu trang của bạn đã nâng cấp trước đó.
4. Git:
   git add on-luyen-phong-van.html
   git commit -m "Add 100 Korean part-time job interviews"
   git push origin main

100 câu mới được THÊM VÀO bộ câu hỏi đang có: tổng số sẽ bằng số cũ + 100.
Script tự sao lưu và không thêm trùng khi chạy lại.
Các phần: quán ăn 30, quán cà phê 30, cửa hàng tiện lợi 30, tổng hợp 10.
Câu trả lời mẫu để tự học, chưa có AI tự chấm phát âm.
